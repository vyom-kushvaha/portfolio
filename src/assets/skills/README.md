# Workbench scene

`workbench-scene.webp` is the optimized 1536 × 1024 artwork generated with the built-in image generation tool. Physical objects are image-based; all skill labels and interactive content are semantic HTML in `src/Skills.jsx`.

The desktop overlay coordinates live in `src/skills.css`. Tablet and mobile recompose the content and reuse cropped regions of the same image through CSS backgrounds. Replace the artwork together with its overlay coordinates.
